# 02_airpurifier_coap

The XIAO joins the home Wi-Fi and streams a **Philips air purifier's** live status straight
off the LAN: no cloud, no app, no Home Assistant. It speaks the purifier's local CoAP API
(UDP 5683, AES-128-CBC payloads), ported to C from
[`aioairctrl`](https://pypi.org/project/aioairctrl/), the library behind
[kongo09/philips-airpurifier-coap](https://github.com/kongo09/philips-airpurifier-coap).

Readings are also being wired into **Supabase** (`supabase/`: schema, apply, verify),
in the Govee monitor's project under `purifier_*` tables. The schema is live and verified;
the firmware upload is next.

Tested on an **AC2220/10**. Design, protocol notes and what the hardware taught:
[`docs/design/02_airpurifier_coap.md`](../../docs/design/02_airpurifier_coap.md).

## Files

The purifier client is the shared component
[`components/philips_air`](../../components/philips_air/); this project is the loop, the
log and (in progress) the Supabase upload.

| File | What |
|------|------|
| `main/main.c` | Loop: log each status, heartbeat, re-register/re-sync on silence |
| `components/philips_air/coap_min.c` | Minimal CoAP codec (build requests, parse replies properly) |
| `components/philips_air/philips_crypto.c` | Payload encrypt/decrypt/verify on mbedTLS + boot self-test |
| `components/philips_air/philips_coap.c` | Socket, sync, Observe register, receive next status |
| `components/philips_air/crypto_vectors.h` | Generated by `tools/crypto_vectors.py` from the Python reference |
| `components/philips_air/test/` | Host test for the codec; a real (redacted) AC2220 status |

## Build

`sdkconfig.defaults.local` (gitignored) needs the Wi-Fi credentials and the purifier's IP:

```
CONFIG_XIAO_WIFI_SSID="…"
CONFIG_XIAO_WIFI_PASSWORD="…"
CONFIG_PURIFIER_HOST="192.168.x.y"
```

```zsh
.claude/skills/xiao-debug/scripts/build.sh 02_airpurifier_coap
.claude/skills/xiao-debug/scripts/flash.sh 02_airpurifier_coap
.claude/skills/xiao-debug/scripts/attach.sh 60
```

Don't know the IP? The purifier ignores ping; send it a CoAP sync instead. Every Philips
CoAP unit on the /24 answers `POST /sys/dev/sync` with 8 hex characters.

Host test for the codec, from `components/philips_air/`:
`cc -I include -o /tmp/t test/test_coap_min.c coap_min.c && /tmp/t`.

Serial commands: `i` heartbeat, `g` re-register (fresh status at the next push), `s`
re-sync, `r` restart.
